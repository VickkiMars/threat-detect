Ablation Analysis: Post-Training Dynamic Range Quantization

Post-training dynamic-range quantization transforms the 32-bit floating point weights into signed 8-bit integers while preserving activations in floating point for maximum numerical fidelity. This achieves a 3.04x compression ratio (172.99 KB → 56.89 KB), well beneath the strict 150.0 KB ceiling mandated by NFR2, allowing the entire model FlatBuffer to be memory-mapped with zero runtime deserialization overhead.
